# Proto Reverie
This is a 3D FPS game done on [Godot](https://godotengine.org/).

This prototype is based upon this [tutorial repository](https://github.com/Artanisx/goblins-den) which I'm currently following along.




# Idea
The prototype must establish the main combat loop (FPS combat, deciding whether to grant powers alongside firearms) and a system that generates a single stage.

So, no multi-level maps or anything like that; basically, the prototype consists of:

1. Level Generation: Upon starting the game, a stage is generated by combining 3–4 preset rooms on a 4x4 grid (using gridmaps and instantiating) that has a start and an end (reaching the end finishes the game).
2. Combat: The combat is FPS-based with a pre-assigned weapon (a simple pistol, perhaps hitscan). The rooms already have enemies placed in them that can see the player and charge at them (simple melee).
3. Progression: The player has a simple health bar; if HP hits zero, they die and it's game over. They also have a number representing EXP. Every kill gives EXP, and every level the player gains 10 max HP and the weapon deals +1 damage (display this on the UI). Very simple player progression.
4. The Boss: In the final room, there is a boss—an enemy with more HP and higher damage. To kill it, the player needs to level up a bit. Essentially, the player's weapon must deal more than the initial 1 damage, or it will be super hard.
5. Victory: Upon killing the boss, the game ends successfully. A screen appears showing the number of kills, the level reached, and the time taken. End of demo.

That’s it, very basic. If it's fun, we will add system extensions, like chests or other features. But before proceeding to an in-depth design, make and finish the prototype.

Once the prototype is done, we can proceed with an in-depth design, deciding on the format, room layouts, balancing, whether there are chests, what kind of items are found, potential healing, equipment, different weapons, powers, etc. But not before creating the aforementioned prototype.
