# Goblin's Den
This is a 3D FPS game done on [Godot](https://godotengine.org/).

![Game screenshot](/images/screenshot_1.png)

The game was created following along [this tutorial series](https://www.youtube.com/playlist?list=PLT26e2jOwbdg) from [The Gamedev Tavern](https://www.youtube.com/@GameDevTavern).

Pixel Art done by me using [Aseprite](https://www.aseprite.org/) while following along.<br>
3D Art done by me using [Blender](https://www.blender.org/) while following along).
